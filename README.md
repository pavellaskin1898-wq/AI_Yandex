# AI Yandex Agent Plugin для Godot 4.6.3

Полноценный плагин для Godot Engine, который интегрирует ИИ-агента на базе **Yandex Alice (YandexGPT / Dialogs API)** с возможностью генерации кода игры прямо в редакторе.

## 📋 Возможности

- 🔐 **Авторизация через Яндекс** — вход по логину и паролю
- 🤖 **Генерация кода через YandexGPT** — создание GDScript-кода по описанию
- 🎮 **Выполнение кода в редакторе** — автоматическое применение сгенерированного кода
- 🖥️ **Удобная док-панель** — интеграция в интерфейс редактора Godot
- 📝 **Логирование** — отслеживание всех операций

## 🚀 Установка

### 1. Установка плагина в Godot

1. Скопируйте папку `addons/AI_Yandex` в ваш проект Godot:
   ```
   ваш_проект/addons/AI_Yandex/
   ```

2. Откройте проект в Godot 4.6.3

3. Перейдите в меню: **Project → Project Settings → Plugins**

4. Найдите плагин **"AI Yandex Agent"** и включите его (поставьте галочку)

5. Док-панель появится в левой части редактора

### 2. Установка Python-сервера

1. Убедитесь, что у вас установлен Python 3.9 или выше

2. Перейдите в папку `python_server`:
   ```bash
   cd python_server
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите сервер:
   ```bash
   python main.py
   ```

   Сервер запустится на `http://0.0.0.0:8000`

## 🔧 Настройка

### Настройка YandexGPT

В файле `python_server/main.py` найдите строку:

```python
"modelUri": "gpt://b1gxxxxxxxxx/yandexgpt-lite",
```

Замените `b1gxxxxxxxxx` на ваш **Folder ID** из Yandex Cloud.

Для получения Folder ID:
1. Зайдите в [Yandex Cloud Console](https://console.cloud.yandex.ru/)
2. Выберите каталог
3. Скопируйте ID каталога

### Получение IAM-токена

Плагин автоматически получает IAM-токен после авторизации через Яндекс.Паспорт.

> ⚠️ **Важно:** Текущая реализация использует симулированную аутентификацию для демонстрации. Для продакшена необходимо реализовать полную аутентификацию через Yandex Passport с обработкой CSRF-токенов.

## 📖 Использование

### 1. Авторизация

1. В док-панели введите ваш **Yandex Login** и **Password**
2. Нажмите кнопку **"Войти"**
3. При успешной авторизации статус изменится на **"Вошёл как: [ваш логин]"**

### 2. Генерация игры

1. В поле **"Game Generation Prompt"** введите описание игры
   - Пример: *"Create a simple platformer game with a player character that can jump and move left/right"*
2. Нажмите кнопку **"Сгенерировать игру"**
3. Ожидайте ответа от YandexGPT
4. Сгенерированный код будет отправлен в Godot для выполнения

### 3. Просмотр логов

Все операции отображаются в нижней части док-панели в разделе **"Logs & Output"**.

## 🔌 API Endpoints Python-сервера

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Проверка статуса сервера |
| POST | `/auth` | Аутентификация пользователя |
| POST | `/generate` | Генерация кода игры |
| POST | `/code` | Отправка кода в Godot |
| GET | `/status` | Статус и список пользователей |

## 🔌 HTTP-сервер Godot

Godot-плагин запускает HTTP-сервер на `127.0.0.1:8765` для приёма команд от Python-сервера.

### Endpoints:

- **POST /execute** — Выполнить GDScript-код в редакторе
- **POST /auth** — Получить уведомление об аутентификации
- **GET /status** — Проверить статус сервера

## ⚠️ Важные замечания

### Безопасность

- ⚠️ **Не используйте этот плагин с реальными паролями в продакшене!**
- Текущая реализация предназначена для демонстрации и тестирования
- Для продакшена используйте OAuth2 flow вместо аутентификации по паролю
- Пароли не сохраняются в открытом виде (используется `SecretStr` в Python)

### Требования к Godot

- **Версия:** Godot 4.6.3.stable.official или новее
- **GDScript:** Версия 2.0
- **Права доступа:** Плагин требует доступа к EditorInterface

### Ограничения

- Генерация кода зависит от качества промта
- YandexGPT может генерировать некорректный код
- Не все типы игр могут быть созданы автоматически
- Требуется стабильное интернет-соединение
