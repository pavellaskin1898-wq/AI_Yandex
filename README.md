# AI Yandex Agent — Плагин для Godot 4.6

Интеллектуальный ассистент для разработки игр в Godot Engine на базе **YandexGPT** и **Yandex Alice**. Генерирует GDScript код, создаёт файлы проекта и помогает с разработкой через удобный интерфейс в редакторе.

## Возможности

- 🤖 **ИИ-агент на YandexGPT** — генерация кода, объяснение концепций, помощь в разработке
- 🔐 **Авторизация через Яндекс** — вход по логину/паролю с безопасным хранением токенов
- 💬 **Чат-интерфейс** — общение с ИИ прямо в редакторе Godot
- 📁 **Генерация файлов** — автоматическое создание `.gd` скриптов и сцен
- ⚙️ **Настройки модели** — выбор модели (yandexgpt-lite/yandexgpt), температура, лимит токенов
- 📊 **Логи и отладка** — подробные логи всех запросов и ответов

## Структура плагина

```
addons/AI_Yandex/
├── plugin.cfg              # Метаданные плагина
├── ai_agent_plugin.gd      # Точка входа (EditorPlugin)
├── http_server.gd          # HTTP сервер для связи с Python
├── dock_ui.tscn            # Сцена UI панели
├── dock_ui.gd              # Логика UI
├── yandex_client.gd        # HTTP клиент к Python-бэкенду
└── config.gd               # Менеджер конфигурации

python_server/
├── main.py                 # FastAPI сервер
├── yandex_auth.py          # Авторизация в Яндексе
├── yandex_gpt.py           # Клиент YandexGPT API
├── godot_bridge.py         # Мост для отправки кода в Godot
└── requirements.txt        # Python зависимости
```

## Установка

### 1. Установка плагина в Godot

1. Скопируйте папку `addons/AI_Yandex/` в ваш проект Godot
2. Откройте Godot Editor
3. Перейдите в `Project → Project Settings → Plugins`
4. Найдите **"AI Yandex Agent"** и включите галочку **Enable**
5. Док-панель появится в правой нижней части редактора

### 2. Установка Python бэкенда

```bash
cd python_server

# Создание виртуального окружения (рекомендуется)
python -m venv venv

# Активация виртуального окружения
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python main.py
```

Сервер запустится на `http://127.0.0.1:8000`

### 3. Настройка подключения

1. В док-панели Godot перейдите на вкладку **"Настройки"**
2. Убедитесь, что **Python URL** = `http://127.0.0.1` и **Python порт** = `8000`
3. Нажмите **"Сохранить"**

## Использование

### Авторизация

1. Перейдите на вкладку **"Авторизация"**
2. Введите email и пароль от аккаунта Яндекс
3. Нажмите **"Войти"**
4. После успешного входа статус изменится на "Подключено"

> ⚠️ **Безопасность**: Пароль не сохраняется. Сохраняется только OAuth-токен в зашифрованном виде.

### Работа с чатом

1. Перейдите на вкладку **"Агент"**
2. Введите задачу в текстовое поле, например:
   - *"Напиши скрипт для игрока с прыжками и движением"*
   - *"Как создать систему диалогов в Godot?"*
   - *"Сгенерируй код для арканоида"*
3. Нажмите **"Отправить"** или **"Сгенерировать игру"**
4. Ответ ИИ появится в чате

### Генерация игры

Кнопка **"Сгенерировать игру"** создаст базовую структуру проекта:
- Скрипты для основных узлов
- Начальную сцену
- Базовую логику игры

Примеры запросов:
- *"Создай платформер с сбором монет"*
- *"Сделай топ-даун шутер с врагами"*
- *"Арканоид с бонусами и уровнями"*

### Вкладка "Логи"

Содержит сырые логи всех HTTP запросов для отладки.

## API Endpoints Python сервера

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/login` | POST | Авторизация (email, password) → oauth_token, iam_token |
| `/chat` | POST | Запрос к YandexGPT (prompt, context) → text, code |
| `/generate_game` | POST | Генерация игры (task) → files[] |
| `/health` | GET | Проверка статуса сервера |

## Требования

- **Godot Engine**: 4.6.3.stable.official или новее
- **Python**: 3.9+
- **Доступ в интернет**: Для работы с YandexGPT API

## Получение API ключа Yandex Cloud

Для полноценной работы рекомендуется получить API ключ:

1. Перейдите в [Yandex Cloud Console](https://console.yandex.cloud/)
2. Создайте новый каталог (или используйте существующий)
3. Перейдите в раздел **"Сервисные аккаунты"**
4. Создайте сервисный аккаунт с ролью `ai.llm.user`
5. Создайте API ключ для сервисного аккаунта
6. Используйте ключ в настройках (опционально)

## Troubleshooting

### Ошибка подключения к Python серверу

- Убедитесь, что сервер запущен (`python main.py`)
- Проверьте порты в настройках плагина
- Проверьте firewall (порт 8000 и 9876 должны быть открыты локально)

### Ошибка авторизации

- Проверьте правильность email/пароля
- Убедитесь, что аккаунт Яндекс активен
- Попробуйте использовать двухфакторную аутентификацию (требуется App Password)

### Код не выполняется

- Проверьте синтаксис GDScript (должен соответствовать Godot 4.6)
- Убедитесь, что код содержит метод `_run()` для выполнения
- Смотрите логи во вкладке "Логи"

### YandexGPT не отвечает

- Проверьте наличие доступа к Yandex Cloud API
- Убедитесь, что IAM токен действителен
- Попробуйте переавторизоваться
